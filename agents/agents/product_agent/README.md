# Product Description Agent

## Purpose

The Product Description Agent generates ecommerce content for museum-store merchandise.

### Inputs

- Product title
- Artist name
- Vendor description
- Category
- Material
- Collection

### Outputs

- Shopify product description
- SEO meta description
- Suggested tags
- Suggested keywords
- Collection recommendations

## Use Cases

- New product onboarding
- Product description refreshes
- SEO optimization
- Artist-made merchandise
- Museum store collections
