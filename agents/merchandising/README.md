# Merchandising Agents

The Merchandising domain focuses on products, artists, collections, and customer-facing content.

## Purpose

These agents help create, optimize, and manage content that supports product discovery, storytelling, and sales.

## Current Agents

### Product Agent

Generates:

- Shopify product descriptions
- SEO meta descriptions
- Product titles
- Product tags
- Keywords
- Cross-sell recommendations

### Content Agent

Creates:

- Collection descriptions
- Landing page content
- Marketing copy
- Educational content

## Planned Agents

### Artist Agent

Generates:

- Artist biographies
- Artist stories
- Collection narratives
- Exhibition-inspired content

### Collection Agent

Supports:

- Collection planning
- Category descriptions
- Merchandising recommendations

### Product Enrichment Agent

Enhances:

- Product attributes
- Product metadata
- Product storytelling

## Outputs

- Product listings
- Collection pages
- Artist profiles
- Marketing content
- SEO content
