# Reporting Agents

The Reporting domain transforms information generated by other agents into actionable summaries and decision-support documents.

## Purpose

These agents consolidate insights from across the repository and deliver clear, executive-level reporting.

## Planned Agents

### Executive Summary Agent

Creates:

- Weekly intelligence reports
- Leadership briefings
- Action-item summaries
- Strategic recommendations

### SEO Reporting Agent

Summarizes:

- SEO findings
- AEO opportunities
- Search performance insights

### Market Intelligence Reporting Agent

Compiles:

- Competitor findings
- Trend observations
- Product opportunities

### Operations Reporting Agent

Tracks:

- Workflow activity
- Agent output history
- Repository performance metrics

## Outputs

- Weekly reports
- Monthly summaries
- Executive briefings
- Action plans
- Leadership dashboards

## Reporting Philosophy

Reports should be:

- Concise
- Actionable
- Evidence-based
- Business-focused
- Easy to share with stakeholders
